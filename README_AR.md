# سيّار | SAYYAR — ملفات المصدر

هذه نسخة مصدر متقدمة كبداية عملية، وليست APK مبنياً ومختبراً مسبقاً. ابنِها عبر GitHub Actions ثم اختبرها على هاتف حقيقي.

## الموجود حالياً
- واجهة عربية داكنة بألوان فحمية وخضراء.
- خريطة تفاعلية من OpenStreetMap.
- طلب إذن GPS ومحاولة تحديد الموقع الحالي.
- بحث فعلي عن الأماكن باستخدام Nominatim عند الضغط على زر البحث.
- اختيار نتيجة كوجهة.
- حساب مسار سيارة عبر خادم Valhalla التجريبي العام.
- رسم خط المسار وعرض المسافة والوقت التقريبيين.
- بدء الملاحة مع تحديث الموقع وقراءة تعليمات المناورة عبر Flutter TTS إذا كان الصوت العربي متاحاً على الهاتف.

## حدود مهمة
- هذا إصدار أولي قابل للبناء والاختبار، ولا ندّعي أنه خضع لاختبار بناء فعلي داخل هذه الحزمة.
- خدمات Nominatim وValhalla العامة لها سياسات استخدام وحدود؛ لا تستخدمها بكثافة ولا تضمن توفرها دائماً. Valhalla يطلب من التطبيقات المنشورة التي تستخدم الخادم التجريبي التواصل معهم وإرسال X-Client-Id.
- خريطة flutter_map الحالية ثنائية الأبعاد؛ لا توجد ملاحة ثلاثية الأبعاد في هذا الإصدار.
- الصوت يعتمد على محرك TTS والأصوات المثبتة في الهاتف. التنبيهات الصوتية هنا أولية ويجب اختبارها ميدانياً قبل الاعتماد عليها أثناء القيادة.
- لا يوجد ازدحام مباشر، بلاغات، خرائط أوفلاين، أو إعادة توجيه ذكية كاملة حالياً.
- بحث Nominatim يُرسل بعد الضغط على زر البحث فقط، وليس تلقائياً مع كل حرف، التزاماً بسياسة الاستخدام.
- يلزم الإنترنت لعرض الخريطة والبحث وحساب المسار.

## بناء APK من GitHub
1. ارفع `lib/main.dart` و`pubspec.yaml` وملف workflow إلى مستودع GitHub.
2. افتح تبويب Actions.
3. اختر `Build SAYYAR APK`.
4. اضغط `Run workflow`.
5. بعد نجاح التشغيل افتح صفحة التشغيل ونزّل artifact باسم `SAYYAR-APK`.
6. فك ضغط ZIP لتحصل على `app-debug.apk`.
